Reader mode integration guide

This guide explains how a document reader preserves semantic structure during translation.

Requirements

  • Keep every heading at its original level.
  • Preserve bold terms, emphasis, and linked references.
  • Never translate source code such as node.nodeValue = text.

Compatibility table

Content typeExpected behavior
ParagraphsTranslate visible English prose.
Code blocksKeep the original source unchanged.
When safe mapping is impossible, retain the original text.
