一个交互式 UI 术语学习实验室——不用死记硬背，用鼠标和手指感受每个术语的真实含义。

🖱️

Hover

悬停状态
👆 试试将鼠标悬停在按钮上
Hover（悬停）指鼠标指针停留在某个 UI 元素上时触发的视觉反馈。它向用户传递一个关键信号："这个元素是可以交互的"。常见表现包括颜色变化、阴影增强、轻微放大等。
👆

Active

按下瞬间
🖱️ 按住按钮感受「按下」的瞬间
Active（激活态）是用户点击元素并按住不放时的瞬间状态。它给用户即时的物理反馈——"我确实按到了"。通常表现为元素缩小、颜色加深或阴影内陷。
⌨️

Focus

焦点状态
👆 点击输入框使其获得焦点
Focus（焦点）表示当前哪个元素正在接收键盘输入。清晰的焦点指示器（如高亮边框）对无障碍访问至关重要——它让键盘用户知道自己在页面的哪个位置。
🚫

Disabled

不可用状态
👀 对比两个按钮的视觉差异
Disabled（禁用态）表示某个操作当前不可用。通过降低透明度、变为灰色、移除交互光标，清晰告诉用户"这个按钮暂时不能点"——避免用户困惑为什么点了没反应。
🌊

Transition

过渡动画
🎯 点击按钮，观察方块如何平滑过渡
Transition（过渡）让元素在两种状态之间平滑变化，而不是突兀地跳变。它是流畅用户体验的基石——对比一下：有过渡 vs 没有过渡，哪个更舒服？
💫

Micro-interaction

微交互
0 次点赞
❤️ 点击爱心，感受微交互的愉悦感
Micro-interaction（微交互）是完成单个小任务的短暂动画反馈。点赞、开关切换、下拉刷新——这些微小瞬间让产品变得有生命力，增强用户的情感连接。
⏳

Loading

加载状态
✅
⏳ 点击按钮模拟数据加载过程
Loading（加载态）告诉用户"系统正在处理，请稍等"。好的加载设计能降低用户的等待焦虑——一个流畅的 spinner 或进度条让等待变得可接受，甚至愉悦。
💬

Tooltip

悬浮提示
悬停我查看提示 📌 这是一个 Tooltip！
👆 将鼠标悬停在虚线框上
Tooltip（工具提示）是用户悬停或长按某个元素时出现的简短说明浮层。它提供即时的上下文帮助，不需要用户离开当前页面去查文档。
📋

Modal

模态弹窗
🔲 点击按钮打开一个模态弹窗
Modal（模态弹窗）是一个覆盖在主内容之上的对话框，强制用户与之交互后才能继续操作。它用于聚焦用户注意力——确认操作、填写表单、查看详情等场景。

Card

卡片设计
🖼️
设计原则
卡片将相关内容分组，便于用户快速扫描和点击。

Card（卡片）是 UI 设计中最常见的容器模式。它将相关信息打包成一个可识别、可操作的单元。卡片通常有清晰的边界、轻微阴影，悬停时会上浮。

Toast

轻提示
🔔 点击按钮查看右上角的 Toast 通知
Toast（轻提示）是一种短暂出现、自动消失的非模态反馈。它用于告知操作结果（"保存成功！"），不打断用户当前流程——出现几秒后自动消失。

Skeleton（骨架屏）是内容加载前的占位符。它勾勒出即将出现的内容的大致形状，让用户感知到页面正在加载，减少等待的不确定感。

Toggle（开关）用于在两个互斥状态间快速切换，如开/关、启用/禁用。它比复选框更直观——一眼就能看出当前状态。

Accordion

手风琴/折叠

UI（User Interface）设计关注产品界面的视觉呈现和交互逻辑，包括布局、配色、字体、动效等。

UX（User Experience）关注用户使用产品时的整体感受——是否好用、是否令人愉悦、是否高效。

👆 点击标题展开内容
Accordion（手风琴/折叠面板）允许用户展开/折叠内容区域，在有限空间内按需显示信息。它是渐进式披露的经典实现——先给概要，想看详情再展开。

Ripple

👆 点击按钮观察波纹从触点扩散
Ripple（波纹/涟漪）是 Material Design 的标志性交互。点击瞬间从触点产生圆形波纹向外扩散，给用户即时的触觉隐喻——"你确实点到了这里"，类似水面的涟漪。

Badge（徽标/角标）是附着在图标或元素上的小型标记，通常显示未读数量或状态变化。它用最小的视觉空间传递关键信息——用户扫一眼就知道有事情需要处理。

Progress Bar（进度条）显示一个操作的完成比例。与 Loading spinner 不同，它给出确定的进度信息——用户知道还要等多久，等待焦虑感大大降低。

👋 这是一个 Modal 弹窗

模态弹窗会覆盖页面其余部分，阻止用户与背景内容交互。 你需要先处理弹窗中的内容（阅读、确认或关闭），然后才能继续操作页面。 这在需要用户集中注意力做出决策时非常有用。

📂 抽屉面板
